# 织思 Weave 原型

这是一个无需安装依赖的单页交互原型。

## 打开方式

在文件管理器中双击 `index.html`，用 Chrome、Edge 或其他现代浏览器打开即可。原型不需要启动服务器、配置 API Key 或联网。

## 演示路径

1. 点击地图中的「怎样不中断当前任务地探索侧问题？」节点。
2. 点击右侧「从此处开支线」。
3. 在右下角输入一个新问题并发送，观察新节点如何接在当前节点后面。
4. 点击「回到上一步」或路径中的上级节点，回到原路线。
5. 试试顶部搜索、节点收藏和地图缩放。

## 文件

- `index.html`：可点击原型，包含界面和交互逻辑。
- `产品文档.md`：第一阶段产品说明书、MVP 范围与待验证假设。

原型示例数据和本地操作记录保存在浏览器的 `localStorage`。输入框会创建图谱节点，但 AI 回复为模拟内容。
